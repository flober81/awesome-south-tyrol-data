# Contributing

Suggestions are welcome, as a pull request or as an issue with the link.

## What fits

- Open data, APIs and tools about South Tyrol (Südtirol / Alto Adige).
- Free to use and publicly reachable. Sources behind a paywall or a login only are left out.
- Official sources and established projects. No company listings or advertising.

## How to write an entry

Add it to the matching section and keep the format:

```
- [Name](link) - One sentence on what it offers.
  `Access` · formats · licence · key
```

- **Access:** `API`, `Download`, `OGC` or `Web`.
- **Licence:** as stated by the source. If it differs per dataset or record, say so.
- **Key:** write `no key` only if the data can be read without registering.

Check the link before you submit. All links are also checked automatically once a month.

Place names in South Tyrol are a sensitive topic. Please link to official or established sources and do not add naming debates.
